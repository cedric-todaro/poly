\begin{exo}
	À l'aide de l'identité remarquable la plus adaptée, développer les expressions algébriques suivantes.
	\vspace*{-2mm}
	\begin{multicols}{2}
		\begin{enumerate}[label=\alph*)]
			\item $(x + 11)^2$
			\item $(3x - 7)^2$
			\item $\left( x - \dfrac{2}{3} \right)\left( x + \dfrac{2}{3} \right)$
			\item $(5x - 9)(5x + 9)$
			\item $(2x - 1,5)^2$
			\item $(x + \sqrt{2})^2$
		\end{enumerate}
	\end{multicols}
\end{exo}
