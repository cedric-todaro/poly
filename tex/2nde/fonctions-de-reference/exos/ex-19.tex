\begin{exo}{}
	À l'aide de la courbe représentative de la fonction inverse, résoudre dans $\R$ les inéquations suivantes :
	\vspace*{-2mm}
	\begin{multicols}{2}
	\begin{enumerate}[itemsep=2mm]
		\item $\dfrac{1}{x} \le 1$
		\item $\dfrac{1}{x} \le 0$
		\item $\dfrac{1}{x} \le \dfrac{-1}{2}$
		\item $\dfrac{1}{x} \ge 1$
	\end{enumerate}
	\end{multicols}\vspace*{-2mm}
\end{exo}
